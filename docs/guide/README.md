# The Waybill Guide

So you're the new hire. Pull up a crate.

You know git. You know Claude Code. You've never seen waybill, and somebody just handed you a slip
full of words like docket, bay and stamp. That's what this guide is for.

I'm the Dispatcher. I don't drive, I don't load, and I don't remember yesterday. I read the
paperwork and tell you which truck to get in. By the end of the first chapter, so will you.

| Chapter | What's in it |
| --- | --- |
| [The ride-along](01-ride-along.md) | One change, `feat/thing`, from the trunk through all seven legs to cleanup |
| [The clipboard](02-glossary.md) | Every word on a waybill, each with a literal git translation |
| [The reference](03-reference.md) | Slash commands, the CLI and its flags, booking keys, settings and prerequisites |

Start with the ride-along. Keep the other two in your back pocket.

Haven't installed it yet? The [main README](../../README.md#install) covers the plugin and the
`waybill` command. Come back when both are in.
