Scope — the --markdown waybill form is not in the ride-along

Context
contract.md:58 lists showing the --markdown form beside each terminal waybill (from tests/golden/<leg>.md) under In Scope, but its rationale reads like a reason to leave it out, and spec.md does not mention it anywhere.
Decision
Left it out and followed the spec. Test 2 bans a golden's first line from any non-waybill fence, and the markdown goldens carry that line, so adding them would need a second fence type and a second golden check.
Alternative
Adding ```waybill-md fences matched against tests/golden/<id>.md. That doubles the sample count and needs a test change the spec doesn't describe.

tests/guide.test.js — the Prerequisites slice runs to EOF

Context
The spec says to slice from ## Prerequisites to the next ## . Prerequisites is the reference's last section, so there is no next heading, and the copied section() helper asserts when its until heading is missing.
Decision
I used section() without until, then cut at the next \n## if there is one, otherwise at EOF.
Alternative
Adding a trailing section after Prerequisites just so the test has an end marker.

tests/guide.test.js — fence parser and commands listing

Context
The spec shows a fences() stub and says to "glob" commands/.
Decision
fences() asserts that no fence is left open at EOF, so a missing close fence can't swallow the rest of a chapter. The commands are listed with fs.readdirSync, the same way tests/commands.test.js does it, rather than with fs.globSync, which is newer on Node 22.
Alternative
fs.globSync, and a parser that silently drops an unclosed fence.

01-ride-along.md — how the bay golden is framed

Context
tests/golden/bay.txt is the waybill for a branch that is checked out in the main checkout and has no bay (tests/fixtures/bay.js). On the trunk, the rookie runs waybill bay feat/thing directly, and that prints the next leg's handover, not this waybill.
Decision
The ride-along shows the bay golden as what the counter hands you if you had cut the branch by hand in the main checkout, so the sample stays true to the state that produces it.
Alternative
Presenting the bay golden as the output of waybill bay, which would be inaccurate.
